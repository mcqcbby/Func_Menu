# 常见问题

## GitHub Pages 页面只有文字，没有完整界面

说明发布的不是 MkDocs Material 构建后的 `site/`，或者 Pages 发布源设置不对。

正确设置：

```text
Settings → Pages → Source → GitHub Actions
```

然后运行：

```text
Actions → Deploy MkDocs Material to Pages
```

## 菜单打不开

检查：

```text
是否手持钟
行为包是否启用
实验玩法是否开启
内容日志是否报错
```

## 表单打不开

本地存档中，先关闭：

```text
聊天和命令
```

再重新点击菜单按钮。

## 公会、称号、签到不显示

这些系统默认关闭，需要管理员开启：

```text
管理员菜单 → 对应管理系统 → 开启
```

## 侧边栏不显示

侧边栏默认关闭：

```text
管理员菜单 → 侧边栏管理 → 开启侧边栏
```
