# 传送系统

## 打开路径

```text
主菜单 → 传送系统
```

## 玩家功能

```text
世界公共点
个人传送点
随机传送
传送玩家 / TPA
返回死亡点
返回上一位置
```

## 个人传送点

添加：

```text
传送系统 → 个人传送点 → 表单添加个人点
```

编辑：

```text
个人传送点 → 选择传送点 → 表单编辑名称
```

移动：

```text
个人传送点 → 选择传送点 → 移动到当前位置
```

删除：

```text
个人传送点 → 选择传送点 → 删除个人点
```

## 世界公共点

玩家路径：

```text
传送系统 → 世界公共点
```

管理员路径：

```text
管理员菜单 → 传送管理 → 公共传送点管理
```

管理员可以添加、编辑、移动和删除公共点。
