# 领地系统

领地系统用于保护玩家建筑区域，防止他人破坏、偷取物资，支持好友共享领地操作权限。

## 打开路径

```text
主菜单 → 领地系统
```

- 普通玩家功能
- 设置领地两点对角
- 创建私人领地
- 查看脚下领地信息
- 我的领地列表
- 传送领地中心
- 领地重命名
- 设置进入欢迎语
- 成员添加/移除
- 自定义成员、访客操作权限
- 删除领地（返还建造金币）
- 权限控制列表

## 成员权限（好友）

```text
- 破坏方块
- 放置方块
- 开门/栅栏门
- 箱子/储物桶开启
- 工作台/熔炉/附魔台
- 按钮/拉杆/压力板
- 农田、蜂箱交互
- 动物实体交互
- 普通方块点击
```

## 访客权限（路人）

```text
- 破坏方块
- 放置方块
- 开门/栅栏门
- 箱子/储物桶开启
- 工作台/熔炉/附魔台
- 按钮/拉杆/压力板
- 农田、蜂箱交互
- 动物实体交互
- 普通方块点击
```

> 默认配置：成员全部权限开启；访客仅开放开门、红石按钮，支持一键重置默认权限。

## 领地保护效果

```text
- 苦力怕、TNT爆炸不会损毁领地内方块
- 无权限操作会直接拦截并弹出提示
- 踏入领地底部显示领地名称与主人
```

## 管理员专属功能

```text
- 管理员菜单 → 全部领地管理
- 免费创建公共领地
- 编辑服务器任意领地
- 强制删除任意领地
- 统一管理全服领地权限
```

## 创建领地完整步骤

1. 打开领地菜单，分别设置点 1、点 2 标记领地对角
2. 两点必须处于同一维度（主世界 / 下界 / 末地不能混用）
3. 填写领地名称、调整领地 Y 高度范围、自定义进入欢迎语
4. 勾选付费确认，完成领地创建

## 创建限制说明

- 领地面积越大，消耗金币越多
- 单个玩家拥有领地数量存在上限
- 领地面积有最小、最大限制
- 圈选区域不能和其他玩家领地重叠

## 常见问题

### 创建提示区域重叠

选取的范围和其他玩家领地冲突，更换空白空地重新标记两点。

### 金币不足无法创建领地

缩小领地占地面积，或通过商店出售物品赚取金币。

### 其他玩家可以破坏我的建筑

确认对方不是领地成员，在权限设置内关闭访客的「破坏方块」权限。

### 领地菜单点击无反应 / 打不开

关闭游戏顶部「聊天和命令」输入框，重新点击菜单按钮即可正常呼出。
