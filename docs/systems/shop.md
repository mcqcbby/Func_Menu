# 商店系统

商店系统分为玩家购买/回收和管理员商品管理。

## 玩家路径

```text
主菜单 → 商店系统
```

玩家可以：

```text
购买商品
回收商品
回收手持物品
```

## 管理员路径

```text
管理员菜单 → 商店管理
```

管理员功能：

```text
出售商品管理
自定义添加出售商品
回收商品管理
自定义添加回收商品
```

## 添加出售商品

填写：

```text
显示名称
物品 ID
每次购买数量
购买价格
```

示例：

```text
显示名称：钻石
物品 ID：minecraft:diamond
每次购买数量：1
购买价格：100
```

## 添加回收商品

填写：

```text
显示名称
物品 ID
回收价格
```

示例：

```text
显示名称：圆石
物品 ID：minecraft:cobblestone
回收价格：1
```
