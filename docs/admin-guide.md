# 管理员使用流程

## 第一步：添加管理员权限

```text
/tag @s add op
```

## 第二步：打开管理员菜单

```text
手持菜单钟 → 打开主菜单 → 管理员菜单
```

## 第三步：推荐配置顺序

### 设置公共传送点

```text
管理员菜单 → 传送管理 → 公共传送点管理
```

建议设置：

```text
主城
资源区
商店区
活动区
出生点
```

### 配置商店

```text
管理员菜单 → 商店管理
```

### 开启签到系统

```text
管理员菜单 → 签到管理 → 签到系统：开启
```

### 开启称号系统

```text
管理员菜单 → 称号管理 → 称号系统：开启
```

### 开启公会系统

```text
管理员菜单 → 公会管理 → 开启公会系统
```

### 设置侧边栏

```text
管理员菜单 → 侧边栏管理
```
