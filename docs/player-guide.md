# 玩家使用流程

## 第一步：获得菜单钟

进入世界后，插件会自动给你一个钟。

```text
物品：钟
用途：打开 Func_Menu 主菜单
```

## 第二步：打开主菜单

```text
手持钟 → 右键方块 → 打开主菜单
```

## 第三步：常用功能

### 设置个人传送点

```text
主菜单 → 传送系统 → 个人传送点 → 表单添加个人点
```

### 使用世界公共点

```text
主菜单 → 传送系统 → 世界公共点 → 选择公共点
```

### 创建领地

```text
主菜单 → 领地系统 → 创建领地
```

### 查看金币

```text
主菜单 → 经济系统 → 查看余额
```

### 购买和回收商品

```text
主菜单 → 商店系统
```

### 签到、称号、公会

这些系统默认关闭，需要管理员开启后玩家才能看到。
