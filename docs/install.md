# 安装教程

这一页教你把 Func_Menu 插件安装到 Minecraft 基岩版世界中。

- [本地安装](#本地安装)
- [服务器安装](#服务器安装)

## 本地安装

&gt; **提示：** 直接导入 `.mcpack` 文件到 Minecraft，新建存档/打开存档设置，打开实验性玩法「测试版 API」，安装 Func_Menu 行为包，进入游戏。

**步骤：**
1. 直接导入 `.mcpack` 文件到 Minecraft
2. 新建存档/打开存档设置
3. 打开实验性玩法「测试版 API」
4. 安装 Func_Menu 行为包
5. 进入游戏

## 服务器安装

&gt; **重要：** 你也可以像常规 addon 一样导入后再上传存档到服务器，可以不按该教程并且省下之后的步骤。

**适用范围：**
- 服务器
- 面板服

&gt; **提示：** 需要你的服务器存档开启测试版 API 并开启作弊（无敌模式）。如果是默认存档，需要上传存档，具体方法如下：

1. 打开服务器文件夹
2. 找到 `worlds` 文件夹
3. 找到你要上传的存档文件夹
4. 上传存档 zip 文件到 `worlds` 文件夹下
5. 解压存档 zip 文件
6. 打开服务器所在目录
7. 找到 `server.properties` 文件
8. 把 `level-name` 的值改为你上传的存档文件夹名
9. 重启服务器
