# 安装教程

这一页教你把 Func_Menu 插件安装到 Minecraft 基岩版世界中。

## 方式一：直接导入

如果插件是 `.mcpack` 或 `.mcaddon` 文件：

```text
双击插件文件 → Minecraft 自动打开 → 等待导入成功
```

然后进入世界设置：

```text
世界设置 → 行为包 → 我的包 → 选择 Func_Menu → 激活
```

## 方式二：手动安装到世界

如果你拿到的是文件夹版本：

```text
1. 打开 Minecraft 世界行为包目录
2. 放入 Func_Menu 插件文件夹
3. 进入世界设置
4. 行为包 → 我的包 → 激活 Func_Menu
```

## 开启实验玩法

Func_Menu 是脚本插件，建议开启：

```text
测试版 API / Beta APIs
假日创作者功能
脚本 API
其他脚本相关实验项
```

## 第一次使用

进入世界后输入：

```text
/tag @s add op
```

然后手持菜单钟打开主菜单。
